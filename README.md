# Әлем елдері

3-сынып оқушыларына арналған география сайты: 195 елдің атауы, астанасы және туы, екі түрлі тест ойыны және «Үздік ойыншылар» тақтасы. Сайт қазақ, орыс және ағылшын тілдерінде.

## Файлдар

- `index.html` — сайттың өзі (бір файл).
- `google-apps-script/Code.gs` — нәтижелерді Google Sheets кестесіне сақтайтын код. Оны GitHub-та емес, script.google.com сайтында іске қосасыз.

## Дереккөздер

- Тулар: [Flag Icons](https://flagicons.lipis.dev) жинағы (авторы Panayiotis Lipiridis, MIT лицензиясы).
- Елдер: БҰҰ-ның 193 мүшесі және 2 бақылаушы мемлекет (Ватикан, Палестина).
- Астаналар 2026 жылғы қарашадағы ресми деректер бойынша.
